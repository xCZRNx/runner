## Wersja Polska (PL)

Prosta gra zręcznościowa 2D typu endless runner, stworzona w języku Python z użyciem biblioteki Pygame. Wciel się w postać, omijaj nadciągające przeszkody (pojawiające się na różnych wysokościach) i postaraj się przetrwać jak najdłużej. Z każdym sekundą przetrwania rośnie Twój wynik.

### Sterowanie
* **Spacja** – Rozpoczęcie gry / Skok / Restart po porażce

### Uruchomienie
1. Wymagany jest zainstalowany Python w wersji 3.x.
2. Zainstaluj bibliotekę Pygame wpisując w terminalu: `pip install pygame`
3. Uruchom skrypt: `python main.py` (lub inna nazwa Twojego pliku)

### Wymagane pliki
Do poprawnego działania gra potrzebuje odpowiednich zasobów w folderze z projektem:
* `font/Pixel.ttf` - plik z czcionką
* `graphics/` - folder z grafikami (pixels.png, sky.png, ground.png, wieczorek.png, ue_fl.png, vat.png, green.png)

## English Version (ENG)

A simple 2D endless runner arcade game created in Python using the Pygame library. Control your character, dodge incoming obstacles (appearing at different heights), and survive as long as possible. Your score increases with every second you stay alive.

### Controls
* **Spacebar** – Start game / Jump / Restart after game over

### How to run
1. Python 3.x is required.
2. Install the Pygame library by running in your terminal: `pip install pygame`
3. Run the script: `python main.py` (or whatever you named your file)

### Required files
For the game to work correctly, it requires the following assets in the project folder:
* `font/Pixel.ttf` - font file
* `graphics/` - directory containing graphics (pixels.png, sky.png, ground.png, wieczorek.png, ue_fl.png, vat.png, green.png)
